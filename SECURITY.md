# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| other   | :x:                |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

Instead, use **GitHub Security Advisories** so the report stays private until it is triaged and coordinated disclosure is ready:

1. Open the repository **Security** tab on GitHub.
2. Choose **Report a vulnerability** (private vulnerability reporting) and submit the details there.

Maintainers may later publish an advisory ([GHSA](https://docs.github.com/en/code-security/security-advisories/about-github-security-advisories)) after a fix is available.

If you cannot use GitHub for some reason, contact jamesread via https://jread.com so the details are not posted in public trackers.
